# 拆案台 · 「漫道」群职场问答系列

互动式职场咨询案例网页：读者逐步拆案（信息体检 → 线索甄别 → 场景追问 → 拆解展开 → 揭晓复盘），结尾引流加群。

在线地址（GitHub Pages）：https://mandao-nochat.github.io/cases/

## 目录结构

```
/
├── index.html          # 索引页：往期拆案列表 + 群引流
├── case-001/           # 每案一个子目录
│   ├── index.html      # 互动页（通用模板，读同目录 JSON）
│   ├── case-001.json   # 案例内容配置
│   └── assets/         # 二维码等资源
```

## 出新案例流程

1. 复制 `case-001/` 目录为 `case-NNN/`
2. 改写其中的 `case-NNN.json`（六阶段配置：原始问题、信息体检、线索甄别、场景追问、拆解展开、揭晓复盘）
3. 在根目录 `index.html` 的 `.case-list` 里加一张卡片
4. 提交推送即可上线

## 配置 JSON 说明

- `stage_1.critical_ids`：信息体检必须全部选对才能下一步（探索式：选对才显示该项解释）
- `stage_2`：多条关键线索，全选对解锁；陷阱项只提示不解释
- `stage_3`：四张卡片全部点开听完才能下一步
- `stage_4`：点击屏幕任意位置逐步展开，全展开后"揭晓结论"亮起
- `stage_5`：结论 + 金句 + 拆案报告（一键复制）+ 群引流卡
